# Секретарь Евгения Николаевича

Telegram‑бот для передачи сообщений, фото и голосовых сообщений владельцу.  
Пользователь пишет `/start`, затем отправляет текст, фото или голосовое — бот формирует уведомление с данными отправителя и пересылает всё владельцу.

## Функционал

- Приём текстовых сообщений.
- Приём фото (пересылается в наилучшем качестве).
- Приём голосовых сообщений.
- Автоматическое формирование уведомления владельцу: имя, username, ID, время, текст/подпись.
- Команды:
  - `/start` — начать передачу сообщения.
  - `/cancel` — отменить передачу.
- Защита от случайных команд: если в режиме ожидания пользователь пишет команду, бот просит использовать `/cancel` или `/start`.
