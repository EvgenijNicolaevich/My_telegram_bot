# Секретарь

Telegram‑бот для передачи сообщений владельцу.  
Пользователь пишет `/start`, затем отправляет текст — бот формирует уведомление с данными отправителя и пересылает всё владельцу.

## Функционал

- Приём текстовых сообщений.
- Автоматическое формирование уведомления владельцу: имя, username, ID, время, текст/подпись.
- Команды:
  - `/start` — начать передачу сообщения.
  - `/cancel` — отменить передачу.
- Защита от случайных команд: если в режиме ожидания пользователь пишет команду, бот просит использовать `/cancel` или `/start`.
- Информация о пользователе хранится в программе и при завершении передачи сообщения удаляется.

## Установка и запуск

### 1. Подготовка окружения

Требуется Python 3.7+ и библиотека `pyTelegramBotAPI`.

Если запускаешь на компьютере:
`pip install pyTelegramBotAPI`

Если запускаешь на смартфоне:
Программа полностью протестирована и стабильно работает на `Android` в приложении `Pudroid 3`.
Для запуска нужно установить библиотеку `pyTelegramBotAPI`через вкладку `pip` в приложении.
